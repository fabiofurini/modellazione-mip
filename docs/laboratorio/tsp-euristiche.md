# TSP: nearest neighbour contro giro ottimo

Il giro del nearest neighbour si costruisce passo passo, poi il 2-opt lo migliora: si confronta con il giro ottimo, con la lunghezza di entrambi. Trascina le città; ◀ ▶ un passo alla volta, «Esegui» per vederli tutti.
