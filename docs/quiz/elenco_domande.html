mip-f-001 · livello facile · dispensa
Un modello di ottimizzazione ha obiettivo e vincoli lineari; alcune variabili sono binarie, alcune intere e altre continue. A quale classe appartiene?
  1. MILP (programmazione lineare intera mista)
  2. LP (programmazione lineare)
  3. ILP (programmazione lineare intera)
  4. BIP (programmazione lineare binaria)
Spiegazione. Sono i domini a distinguere le classi: tutte continue è LP, tutte intere ILP, tutte binarie BIP; un modello con variabili intere (o binarie) e continue insieme è un MILP.

Problema di **massimo**. $\zmilp$ è l'ottimo del MILP, $\zlp$ quello del rilassamento lineare con le sole $x \ge 0$, $\zlpp$ quello con anche $x \le 1$, $\zdual$ l'ottimo del duale del rilassamento. $\bar x$ è ammissibile per il MILP, $\bar\pi$ per il duale. Quale catena è corretta?

  2. $\lb(\bar x) \le \zdual \le \zmilp \le \zlpp \le \ub(\bar\pi)$

  4. $\lb(\bar\pi) \le \zdual = \zlp \le \zlpp \le \zmilp \le \ub(\bar x)$

mip-f-052 · livello facile · dispensa

mip-f-069 · livello facile · dispensa

  4. Non vale in alcuna soluzione ottima, qualunque sia $f_j$

mip-f-071 · livello facile · dispensa

  4. Un numero grande qualsiasi, per esempio $100$
Spiegazione. Il coefficiente giusto è il più piccolo limite superiore della quantità quando l'impianto è aperto: la capacità. Un big-M «grande abbastanza» è valido ma indebolisce molto il rilassamento; $K = 1$ taglierebbe le soluzioni con $q_j > 1$.
mip-f-072 · livello facile · dispensa

  2. $q_j \ge \ell\, y_j$ e $q_j \le c_j$
  3. $\ell \le q_j$ e $q_j \le c_j$
  4. $\ell\, y_j \le q_j$ e $q_j \le c_j\, y_j$

Quali sono $(\lb, \ub)$?

  4. $(4, \tfrac{53}{6})$
